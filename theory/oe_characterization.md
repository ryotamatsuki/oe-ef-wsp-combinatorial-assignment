# OE characterization on the six-type domain

For a feasible allocation `x=(p_i,q_i,r_i,z_i)_i`, define `L={A,E,C}` and `R={B,F,D}`.

Astra's analytic characterization states that `x` is OE iff:

1. `r_i=0` for `t_i in {A,B,E,F}`;
2. both capacities bind: `sum_i(p_i+r_i)=sum_i(q_i+r_i)=1`;
3. there is no simultaneous crossed singleton mass: `(sum_{i:t_i in L} q_i)(sum_{j:t_j in R} p_j)=0`.

The explicit mechanism satisfies all three conditions profile by profile. This characterization is over the original continuous fractional feasible set; it is not a candidate-grid result.
